# Programación III - Módulo 4

## Taller grupal: Estructura lineal simple

En este repositorio estaremos desarrollando una historia sencilla utilizando Python.

La actividad consiste en solicitar algunos datos al usuario, como su nombre, edad y ciudad de residencia, para después utilizarlos en una historia sobre el protagonista.

## ¿Cómo funciona?

Al ejecutar el programa, se hacen varias preguntas al usuario.

Con las respuestas ingresadas, el programa va mostrando información sobre el personaje y construyendo una historia que continúa con los aportes de los integrantes del grupo.

Para esta actividad utilizamos variables, `input()` y `print()`.

## ¿Cómo ejecutarlo?

Desde la terminal:

`python historia.py`

## Trabajo en equipo

La idea es que cada integrante agregue una parte de la historia, manteniendo lo que ya han trabajado los demás compañeros.

Los cambios se comparten mediante GitHub para que podamos integrar las diferentes contribuciones en un mismo programa.
